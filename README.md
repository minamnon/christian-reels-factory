
# Christian Reels Factory

Automated Christian Facebook Reels Production System.

## Project Goal
Create Arabic Christian videos automatically, from topic selection to final MP4 export.

## Production Pipeline
1. Select a biblical topic.
2. Verify biblical references.
3. Write Arabic narration.
4. Generate Arabic voiceover.
5. Collect licensed visual footage.
6. Generate synchronized subtitles.
7. Render vertical video using FFmpeg.
8. Validate the final video.
9. Prepare Facebook publishing materials.

## Technical Architecture
- Claude: AI production manager.
- MCP: Tool integration.
- Cloudflare Workers: MCP hosting.
- GitHub Actions: Video rendering automation.
- FFmpeg: Video editing and export.
- Free Arabic TTS: Voice generation.

## Output
- MP4 video (1080x1920).
- MP3 voiceover.
- SRT subtitles.
- Script and publishing description.
